## 10. 怎么核对这张表还成立

不跑测试也能做的静态核对：

```powershell
# 1) 云端入口/单 Worker/健康检查是否还在
Select-String -Path .\danmaku_pet\cloud\__main__.py -Pattern "workers=1"
Select-String -Path .\danmaku_pet\cloud\server.py -Pattern "/api/health"

# 2) 客户端是否真的没有 Key 字段
Select-String -Path .\danmaku_pet\client\*.py -Pattern "DEEPSEEK|API_KEY"

# 3) 云端是否真的没有写 .env 的接口
Select-String -Path .\danmaku_pet\cloud\server.py -Pattern "update_env_file|settings_store|/api/settings/llm"

# 4) 旧文件是否真的不在了
foreach ($p in @("danmaku_pet\server.py","danmaku_pet\orchestrator.py","danmaku_pet\inputs\douyin_webcast.py","danmaku_pet\web\app.js")) { "{0} -> {1}" -f $p, (Test-Path $p) }

# 5) 依赖是否还分两份
Get-Content .\requirements-cloud.txt
Get-Content .\requirements-client.txt
```

需要动态核对时，用《部署手册》第 6 节的 `scripts\smoke_test.py`（验证云端）与《开播手册》第 4 节（验证本地执行）。
